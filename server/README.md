# V-Remote Control (PC & Mobile)

Легковесная система удалённого управления мышью и клавиатурой ПК со смартфона из любой точки мира.

## 🚀 Быстрый запуск

1. Запустите файл **`start.bat`** (или выполните команду `python server.py`).
2. В открывшейся консоли отобразится:
   - **Порт:** `8765` (можно изменить в `config.json`)
   - **PIN-код безопасности:** (сохраняется в `pin.txt`)
   - Ваши локальные IP-адреса.

---

## 🌐 Проброс портов (для доступа отовсюду)

Чтобы подключаться из мобильной сети (4G/5G) или другого интернета:
1. **В роутере / Clash Verge**:
   - Протокол: **TCP**
   - Внутренний порт: **`8765`**
   - Внешний порт: **`8765`** (или любой свободный)
   - Внутренний IP: локальный IP вашего компьютера (например, `192.168.1.100`)
2. На телефоне в браузере откройте:
   ```text
   http://<ВАШ_ВНЕШНИЙ_IP>:8765
   ```
3. Введите PIN-код (сохраняется на телефоне, повторно вводить не нужно).

## 📱 Возможности мобильного интерфейса

* **Тачпад:**
  * **1 палец:** Перемещение курсора.
  * **Тап 1 пальцем:** Левый клик (ЛКМ).
  * **Тап 2 пальцами:** Правый клик (ПКМ).
  * **2 пальца вверх/вниз:** Скролл колесом мыши.
  * **Правая полоса тачпада:** Быстрый скролл одним пальцем.
* **Режим удержания:** Кнопка «Удержание» зажимает ЛКМ для удобного выделения или перетаскивания окон (Drag & Drop).
* **Нижняя панель кнопок:** Физические кнопки ЛКМ, Колесо, ПКМ.
* **Быстрые клавиши:**
  * `Win + D` (Свернуть все окна), `Alt + Tab`, `Ctrl + C`, `Ctrl + V`
  * `Esc`, `Tab`, `Enter`, `Del`, Стрелки `▲ ▼ ◄ ►`
  * Громкость: `Vol +`, `Vol -`, `Mute`, `Play/Pause`
* **Ввод текста:**
  * Кнопка **⌨️** — открывает стандартную виртуальную клавиатуру телефона.
  * Кнопка **«Текст»** — позволяет ввести и отправить на ПК любую фразу (русский/английский текст отправляется напрямую в Unicode без рассинхрона раскладок).
* **Автоблокировка экрана (WakeLock):** Экран телефона не гаснет, пока открыта страница управления.
* **Тактильный отклик (Haptic):** Вибрация телефона при кликах.
* **Настройки (⚙️):** Регулировка чувствительности и инверсия скролла.
