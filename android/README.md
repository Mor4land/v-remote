# V-Remote Android Client (Kotlin + Material Design 3 + UDP)

Нативный Android-клиент для ультрабыстрого управления ПК по протоколу UDP.

## 📱 Стек технологий:
- **Язык:** Kotlin 2.0+
- **UI:** Jetpack Compose + **Material Design 3**
- **Сеть:** Асинхронный корутинный сокет `DatagramSocket`
- **Протокол:** Микросекундный бинарный протокол (5–12 байт на дейтаграмму)
- **Обратная связь:** Тактильная виброотдача (Haptic Feedback)
- **Экран:** `FLAG_KEEP_SCREEN_ON` (экран смартфона не гаснет во время сессии)

---

## 🛠️ Сборка APK:

1. Откройте эту папку (`vremote_android`) в **Android Studio**.
2. Дождитесь автоматической синхронизации Gradle.
3. Нажмите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** (или запустите прямо на подключённом телефоне по USB/Wi-Fi).
4. Установите созданный `.apk` на телефон.

---

## 🖥️ Запуск UDP-сервера на ПК:

На стороне компьютера в папке `remote_control` запустите:
```bash
python udp_server.py
```
* Порт по умолчанию: **`8766` UDP**
* PIN безопасности: из файла `pin.txt` (например, `7373`)
