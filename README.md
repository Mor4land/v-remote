# V-Remote (Android & PC)

Высокоскоростная система удалённого управления компьютером со смартфона:
- **Android App:** Нативный Kotlin + Jetpack Compose + **Material Design 3** (чистый бинарный UDP-протокол).
- **Web App / PWA:** Доступ из любого браузера без установки.
- **PC Daemon:** Python Win32 API (`SendInput`), захват экрана в реальном времени (GDI StretchBlt), WebSocket + UDP сервер.

---

## 📁 Структура репозитория

* `android/` — Нативный Android-проект (Kotlin, Jetpack Compose, Material 3, Coroutines UDP Client).
* `server/` — Серверная часть для Windows (видеостример экрана, тачпад, клавиатура, WebSocket и UDP шлюзы).
* `.github/workflows/release.yml` — Автоматическая облачная сборка APK и публикация релизов при пуше тега.

---

## ⚡ Особенности

1. **Микросекундный UDP стек:** 5–12 байт на дейтаграмму, нулевой оверхед, живой замер пинга в приложении (`⚡ RTT ms`).
2. **Живой рабочий стол:** Трансляция экрана Windows в реальном времени с аппаратным курсором.
3. **Два режима:**
   - «🎯 Сенсор» (Direct Touch) — тап по экрану кликает прямо в нужную точку рабочего стола.
   - «🖱️ Тачпад» (Trackpad) — плавное перемещение курсора мыши.
4. **Безопасность:** Авторизация по PIN-коду и блокировка брутфорса при выходе в глобальный интернет.
